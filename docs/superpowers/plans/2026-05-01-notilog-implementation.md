# Notilog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native Android app that intercepts, stores, and organizes notifications to recover deleted messages and search history.

**Architecture:** MVVM with Clean Architecture. Uses `NotificationListenerService` for background interception, Room for local persistence, and Jetpack Compose for the UI.

**Tech Stack:** Kotlin, Jetpack Compose, Room, Hilt, Coroutines, Flow.

- [ ] **Step 1: Implement `onNotificationPosted`**
